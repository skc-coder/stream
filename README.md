# Stream Downloader & Uploader

Automated course video downloader with real-time Google Drive upload via Rclone.

## Setup & Installation

```bash
git clone https://github.com/skc-coder/stream.git
cd stream
pip install -r requirements.txt
```

## Running the Code

```bash
python3 main.py
```

## Update & Run

```bash
git pull && python3 main.py
```
